# Our Marriage Contract — Keepsake Website

A responsive, animated personal commitment website for Mg Min Khant and Mg Linn Thit Aung.

## Features
- Separate signature canvases for each partner.
- Signatures saved in the current browser's local storage.
- Personal vows, a shared covenant, and human-rights principle references.
- Printable layout suitable for browser **Print → Save as PDF**.
- Downloadable JSON summary of the keepsake record.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to finish publishing; the public URL will appear in the Pages section.

## Important limitations
- Signatures are saved only in the browser and device where they were drawn. They are not uploaded to a shared database. Clearing site data can erase them.
- The JSON download is a summary and does not contain the signature image data. Use **Print / Save as PDF** to preserve the visible signatures in a document.
- This is a personal keepsake, not a government-issued, notarised, or legally registered marriage certificate. Recognition of same-sex marriage and legal requirements vary by jurisdiction. The names and birth dates are displayed as provided and are not identity-verified.
- Human-rights texts are linked for context; they do not guarantee that this keepsake has legal effect in any jurisdiction.
